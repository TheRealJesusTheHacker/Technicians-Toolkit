> **Sync rule (standing, set 2026-10-20):** whenever a member tool's repo is updated, the Technician's Toolkit is updated in the same change-set to match it. A member update is not complete until the Toolkit agrees with it — this tracker is where that agreement is recorded.

> **Sync discipline (for every crew that touches this repo):** fetch the live repo immediately before you start editing, and again immediately before you push. Build your change on the current head — never on a snapshot taken earlier in the night. If the head moved while you worked, re-apply your change onto the fresh content before pushing. Never overwrite a newer file with an older base: a silent revert is how sync entries get lost.

This file tracks one question per medic-kit tool: *what is its portable edition, where does it download, and what is queued next?* It is updated on every audit. If a status here and a tool's own README disagree, this tracker is wrong until re-audited — flag it.

## Beerus — BY DESIGN + SHIPS TODAY

- **What the portable is:** Beerus has **two forms** over one engine (owner directive, 2026-10-20). The bootable Destruct Key Pro USB image — flash the image to a USB, boot the target machine from it, wipe, verify, certify — is portable by construction and stays. Alongside it, **Beerus Portable** is a no-install Windows app: unzip `BeerusPortable.zip` on an already-booted machine and run `Beerus.exe` — the same engine, gates, verification, and certificates, refusing (by design, at the gate and engine layers) the drive Windows runs from and the drive the app itself runs from. The app wipes three ways: whole drives, individual files & folders (data overwritten and read back *before* the entry is removed — never mere deletion), and free space. *(The earlier position recorded below — no separate portable download — was superseded by this directive the same day it was written down.)*
- **Made explicit 2026-10-20:** Beerus's README already described the bootable-USB design unambiguously but never used the word "portable"; one additive commit (`289c510a77`) added the explicit line: *"Beerus's portable edition is the bootable USB image itself — the Destruct Key Pro USB is its portable form, with no separate portable download or installer."*

Beerus Portable, the app, is an ordinary portable zip and **joined the bundle as files in bundle v0.2.0** (2026-10-20), hash-verified from Beerus's own release like every other tool — in a `Beerus/` folder of its own, because its top-level `_internal/` support folder shares NitroCore's name and the two cannot share a level (see the bundle section above).
